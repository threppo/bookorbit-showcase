# Attribution and licence notes

## Original Android project

BookOrbit Android was originally developed in
[`deranjer/bookorbit-android`](https://github.com/deranjer/bookorbit-android). This showcase describes
a modified personal fork and does not imply endorsement by the original Android client or BookOrbit
server maintainers.

The original project supplied the native Android foundation. The showcase distinguishes that
foundation from later fork work such as the current audiobook API integration, expanded offline
caching, Books/Audio browsing, server-backed management and requests, persistence recovery,
performance work, Readium integration and the revised Compose interface.

## BookOrbit server

The client connects to the separate
[`bookorbit/bookorbit`](https://github.com/bookorbit/bookorbit) server project. BookOrbit names,
server behaviour and API concepts belong to their respective maintainers.
